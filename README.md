# GoBus – Bus Ticket Booking & Management System

## Overview

GoBus is a Database Management System (DBMS) project developed during my second year of engineering. It is a bus ticket booking and management platform inspired by services like RedBus. The system is designed to streamline the process of managing buses, routes, schedules, passengers, bookings, and ticket information through a structured relational database.

## Features

* User registration and login
* Bus search based on source and destination
* Seat availability checking
* Ticket booking and cancellation
* Bus schedule management
* Passenger information management
* Route and fare management
* Booking history
* Admin panel for managing buses, routes, and schedules
* Relational database with SQL queries for efficient data retrieval

## Technologies Used
